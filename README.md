# 永豐金帳戶管理員

使用永豐金證券 [Shioaji](https://sinotrade.github.io/) API 查詢帳戶資產狀況，並以 PyQt6 圖形介面呈現即時資料與歷史紀錄。

## 功能

### 即時狀態
- 查詢**股票帳戶**的可用餘額、各筆待交割款（含交割日與 T+N 標示）、交割後餘額（現金水位）
- 查詢**期貨/選擇權帳戶**的今日餘額、各項損益及期貨權益數
- 支援多股票帳戶、多期貨帳戶，可於介面中切換顯示
- 跨帳戶合計：現金水位、股票市值、總資產及現金佔比

### 股票庫存（可選）
- 顯示各股票帳戶的持倉明細：股票代號、股票名稱、數量（股）、成本、股價、市值、未實現損益
- 可於「系統設定」中選擇是否顯示此頁籤（隱藏時仍會抓取市值用於總資產計算）

### 歷史資料
- 每次更新自動將帳戶資產快照儲存至本地 SQLite 資料庫
- 可依帳戶篩選，以時間倒序檢視歷史紀錄
- 欄位：日期、可用餘額、T+1 交割、T+2 交割、現金水位、股票市值、總資產、現金佔比、期貨權益
- 自動對帳：下次更新時，若前一交易日的 T+1/T+2 金額與實際入帳不符，會自動修正並重新計算現金水位及總資產

### 其他
- 程式啟動時可選擇**自動更新**帳戶資料
- 帳號資訊可**遮罩顯示**（「-」後以星號取代）
- 帳戶設定儲存時自動驗證 API Key 是否可正常登入

## 環境需求

- Python 3.12+
- [uv](https://github.com/astral-sh/uv)（套件管理）
- 永豐金證券帳戶及 Shioaji API Key

## 安裝

```bash
git clone <repository-url>
cd sj-accountManager
uv sync
```

## 設定

複製或建立 `.env` 檔案（不會被版控）：

```
API_KEY=你的_API_Key
SECRET_KEY=你的_Secret_Key
YOUR_CA_PATH=/path/to/your.pfx    # 可選，啟用憑證交易
YOUR_CA_PASS=憑證密碼              # 可選
HIDE_ACCOUNT_INFO=false            # true = 遮罩帳號「-」後的內容
AUTO_REFRESH=false                 # true = 程式啟動時自動更新
SHOW_STOCK_POSITIONS=false         # true = 顯示股票庫存頁籤
```

也可在程式的**帳戶設定**與**系統設定**選單中直接填寫，設定值會自動寫入 `.env`。

## 執行

**圖形介面（建議）**

```bash
uv run python app.py
```

**命令列模式**

```bash
uv run python main.py
```

## 使用注意事項

- **CA 憑證**：未設定憑證路徑與密碼時，仍可查詢帳戶資料，但無法使用需要憑證的功能。
- **交割款計算**：T+0（當日已入帳）不列入待交割款，現金水位 = 可用餘額 + T+1 + T+2 合計。
- **快照日期**：以交割款中 T+0 的日期作為當天交易日（而非系統日期），確保非交易日執行時日期正確。
- **資料庫**：歷史快照儲存於 `account_history.db`，不會上傳至版控。
- **股票市值**：無論是否顯示股票庫存頁籤，每次更新皆會抓取持倉以計算市值與總資產。

## 專案結構

```
sj-accountManager/
├── app.py          # PyQt6 圖形介面主程式
├── core.py         # Shioaji API 資料抓取層（純資料回傳，不寫 DB）
├── db.py           # SQLite 存取層
├── main.py         # 命令列介面（行為與 app.py 相同，終端輸出）
├── pyproject.toml  # 專案設定與依賴
└── .env            # 敏感設定（不進版控）
```
